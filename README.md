# IslamCal — Alat Hitung Lengkap untuk Muslim Indonesia

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![React](https://img.shields.io/badge/React-18-61dafb?logo=react)](https://react.dev)

Koleksi kalkulator Islam dalam satu aplikasi: zakat, waris, jadwal sholat, konversi kalender Hijriah, dan lainnya. Gratis, offline-ready, tanpa iklan.

---

## Fitur

- 🕌 **Multi-kalkulator** — Zakat, waris, jadwal sholat, konversi Hijriah
- 📅 **Kalender Hijriah** — Konversi tanggal Masehi ↔ Hijriah
- 🌙 **Jadwal Sholat** — Berdasarkan koordinat GPS
- 📱 **PWA** — Installable, bisa dipakai offline
- 🌐 **No Backend** — Semua kalkulasi di browser

---

## Quick Start

```bash
git clone https://github.com/alfindigital/islamcal.git
cd islamcal
npm install
npm run dev
npm run build
```

---

## Stack

- React 18 + Vite + TypeScript
- Tailwind CSS + shadcn/ui
- PWA ready
